# Password Strength Checker

## Overview
This Python program analyzes a password by checking its length and the presence of uppercase letters, lowercase letters, numbers, and special characters. It calculates a score based on these checks and assigns a password strength rating.

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python password_checker.py
```

5. Enter your password to view the analysis report.
